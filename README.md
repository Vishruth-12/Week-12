# Week 12 — Category C Solutions

Solutions are separated into individual Java files and follow the uploaded Week 12 PDFs.

## Coding Assignment — Linked Lists and Stack
1. Problem1_BusRouteStops.java — build and print a linked chain of bus stops.
2. Problem2_LateComersInLine.java — add nodes at the beginning or end.
3. Problem3_BookCopyFinder.java — find first position and count copies in one traversal.
4. Problem4_CancelBooking.java — remove the first matching booking.
5. Problem5_PlateStackOnChain.java — stack implemented using linked nodes.

## Category C Practice Problems
6. Problem6_CampusStaffSalary.java — inheritance and method overriding.
7. Problem7_ClassReportCard.java — validation, grades and early-stop bubble sort.
8. Problem8_LibraryReturnDesk.java — array stack and circular queue, each of size 3.
9. Problem9_PaymentProcessing.java — interface and polymorphism.
10. Problem10_WeeklyRainfallAnalysis.java — seven-day array analysis.
11. Problem11_HostelElectricityBill.java — slab-based electricity billing.

## Compile and run
Compile one source file at a time, for example:

```bash
javac Problem1_BusRouteStops.java
java Problem1_BusRouteStops
```

Each file contains its own main method. Use the matching class name when running a different problem.
